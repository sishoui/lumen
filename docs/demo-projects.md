# ESP32-C3FH4 8 路彩虹流水灯（MVP Demo）

✅ **状态：已验证可正常驱动的 Demo 项目**

本项目为 ESP32-C3FH4 主控 + 8 路 WS2812B 灯带的彩虹流水灯 MVP 示例，
已实际编译、烧录到硬件并通过验证，可直接作为 demo 使用。

---

## 1. 项目信息

| 项目 | 说明 |
|------|------|
| 主控 | ESP32-C3FH4（ESP32-C3 系列，4MB Flash） |
| 驱动框架 | Arduino + FastLED 3.6.0 |
| 构建工具 | PlatformIO（espressif32 平台） |
| LED 类型 | WS2812B（兼容 WS2812），5V 供电 |
| 灯带数量 | 8 路，每路默认 60 颗 |
| 数据引脚 | GPIO 0, 1, 3, 4, 5, 6, 7, 10 |
| 效果 | 8 条灯带同向彩虹色带流动（同相位瀑布 / 错相位波浪） |
| 串口命令 | 亮度 / 速度 / 相位 / 重置 可调 |

## 3. 硬件接线

| ESP32-C3 GPIO | 灯带 DIN |
|---|---|
| GPIO 0 | 灯带 1 |
| GPIO 1 | 灯带 2 |
| GPIO 3 | 灯带 3 |
| GPIO 4 | 灯带 4 |
| GPIO 5 | 灯带 5 |
| GPIO 6 | 灯带 6 |
| GPIO 7 | 灯带 7 |
| GPIO 10 | 灯带 8（建议外部加 10kΩ 下拉） |

**接线要求：**
- 灯带使用 **5V 独立电源** 供电，并与 ESP32-C3 **共地**
- 每路数据线串联 **330Ω 电阻**
- GPIO10 上电期间建议加 **10kΩ 下拉电阻**，避免启动瞬间乱闪

## 4. 构建与烧录

```bash
# 安装依赖
pio pkg install

# 编译
pio run

# 烧录（自动检测端口，或手动指定 upload_port）
pio run -t upload

# 串口监视器（115200）
pio device monitor -b 115200
```

> 若串口被占用（烧录报 port busy），稍等 3 秒重试即可；
> 若出现 COM 口识别问题，请在 `platformio.ini` 中手动设置 `upload_port = COMx`。

---

## 5. 串口命令（115200 波特，NL+CR / LF）

| 命令 | 功能 | 示例 |
|------|------|------|
| `b<0-255>` | 设置亮度 | `b128` |
| `s<1-100>` | 设置流水速度（越大越快） | `s50` |
| `p<0\|1>` | 相位模式：`0`=同相位（瀑布）、`1`=错相位（波浪） | `p1` |
| `r` | 重置灯效 | `r` |
| `h` | 帮助 | `h` |

---

## 6. 可调参数

`src/main.cpp` 顶部「可调参数区」：

| 宏 | 默认值 | 说明 |
|----|--------|------|
| `NUM_STRIPS` | 8 | 灯带数量 |
| `NUM_LEDS_PER_STRIP` | 60 | 每条灯带灯珠数 |
| `LED_PIN_0..7` | 0,1,3,4,5,6,7,10 | 各路数据引脚 |
| `COLOR_ORDER` | GRB | 灯珠颜色顺序（颜色不对可改 RGB/BRG） |
| `DEFAULT_BRIGHTNESS` | 128 | 默认亮度 |
| `DEFAULT_SPEED` | 50 | 默认流水速度 |
| `DEFAULT_PHASE_MODE` | 0 | 0=同相位 1=错相位 |
